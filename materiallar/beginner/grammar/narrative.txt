Unit 8

There is / there are —-- U YERDA BOR

There is + birlikdagi ot (bitta narsa).

There are + ko‘plikdagi ot (ikki va undan ortiq narsa).

1. Darak shakli (Positive)

Biror narsa borligini aytishda ishlatiladi.

● Struktura: There is / There are + ot + joy/o'rin.

● Misollar:

○ There is a book on the table. (Stol ustida kitob bor.)

○ There are five students in the classroom. (Sinfxonada beshta talaba bor.)

2. Inkor shakli (Negative)

Biror narsa yo‘qligini aytishda ishlatiladi. Bu yerda "not" qo‘shiladi.

● Struktura: There is not (isn't) / There are not (aren't) + ot.

● Misollar:

○ There isn't any milk in the fridge. (Muzlatgichda sut yo'q.)

○ There aren't any cars in the park. (Parkda mashinalar yo'q.)

3. So‘roq shakli (Question)

Biror narsa bor yoki yo‘qligini so‘rashda "is/are" so'zlari gap boshiga o'tadi.

● Struktura: Is there / Are there + ot?

● Misollar:

===== PAGE 11 =====
○ Is there a bank near here? (Yqin atrofda bank bormi?)

○ Are there any apples in the bag? (Sumkada olmalar bormi?)

Qisqacha eslatma jadvali:

Shakli Birlik (Singular) Ko'plik (Plural)

Inkor (-) There isn't a cat. There aren't cats.

So'roq (?) Is there a cat? Are there cats?

Talaffuzi: [vud layk]

1. Darak shakli (+)

Struktura: S + would like + to V1 / Obj

2. Inkor shakli (-)

Struktura: S + would + not + like + to V1 / Obj (Qisqartmasi: wouldn't

3. So'roq shakli (?)

Struktura: Would + S + like + to V1 / Obj?

● Would you like to drive BMW? (Siz BMW haydashni xohlaysizmi?)

4. Maxsus so'roq shakli (Wh-)

Struktura: Wh- + would + S + like + to V1 / Obj?

● What would she like to drive? (U nima haydashni xohlaydi?)
